Graphopedia - Wiki Catalogue of Graphs And Charts

Together with my partner, I built an extensive catalogue of graphs and charts that supports content collaborators. The catalogue is implemented as a static website generator. Collaborators can edit each article in Markdown and submit changes through GitHub. The website is built on Gatsby.js and React.js.

The homepage has grid, list, and groups views, displaying all the charts with separate controls for switching between views and sorting. The articles link to each other through relationships defined by tags and properties in Markdown YAML.

Tech: Gatsby.js, React.js, Markdown, YAML, Algolia Doc Search, GitHub

Scope: Development, Design, Research
